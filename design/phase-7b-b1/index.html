WalkOne Template Studio · Phase 7B · B1 mockup checkpoint · round 2

Editor refresh mockups for owner review

Static mockups of the refreshed Template Studio shell, built on the Phase 7A UX architecture. They are pictures of the proposed app, drawn at real pixel sizes. Nothing here is wired to the app, the project format or any app behaviour. Approve or amend the visual direction; implementation (B2 onward) starts only after your sign-off.

  • Based on docs/PHASE_7A_UX_ARCHITECTURE.md (HEAD 710c6bb)
  • Review notes: docs/PHASE_7B_B1_MOCKUP_REVIEW.md
  • Targets: 1920 × 1000 (roomy) and 1426 × 779 (Windows 125 %)
  • Light default · Comfortable size default
  • Dark and Compact shown for comparison
  • Sample content is fictional
Use 1:1 on a real 1920 × 1080 screen to judge density.

Visual direction

Feel

  • A professional creative tool: Canva-easy to start, Figma-precise to finish.
  • Quiet, cool-neutral chrome so the artwork is the brightest thing on screen.
  • One accent (indigo) for selection, focus and the primary action. Status colours mean status only.
  • Comfortable size by default: bigger buttons and text for people new to design tools.
  • Words before icons: rail labels, view-bar state words, toolbar verbs.

Principles shown

  • Most-used controls first; secondary sections collapse with a one-line summary.
  • Every state uses an icon and a word as well as colour.
  • No primary action below a fold: footers stick, summaries pin.
  • The artboard is never themed. Overlays keep their hue in both themes.

Screen sizes

  • Roomy: 1920 × 1000 CSS px (1920×1080 at 100 %, window maximised).
  • Compact: 1426 × 779 CSS px (the Windows laptop at 125 %), also stands in for 1536 × 800.
  • Tiers switch on width and height separately (7A §30). The canvas never drops below 520 × 400.

Design system

Three token layers (primitives → semantic → components). The sheet shows the semantic layer and the main components in both themes.

Typography

  • Inter for the interface (bundled, so Mac and Windows look the same), tabular numbers in every numeric field.
  • Scale: 11 caps labels · 12 labels, helper, badges · 13 body, values, controls · 14 document title, drawer titles · 16 dialog titles · 20 section headings · 28 Start display.
  • Weights: 400 text, 500 controls, 600 titles and values that matter, 700 counts.

Spacing and density

  • 4-pt scale: 2 · 4 · 6 · 8 · 12 · 16 · 20 · 24 · 32 · 40.
  • Comfortable (default): 34 px buttons and fields, 38 px primary, 36 px layer rows, 14 px text. Compact: 28 px, 13 px text.
  • Comfortable chrome: top bar 52 · view bar 48 · section header 40 · status bar 30 · rail 80.
  • Radii: 4–6 controls, 8 cards, 10 dialogs, drawers and popovers. Pills are kept for nothing but toggles.

Decide

  • Interface font: Inter, bundled (V1, decided).
  • Kind colours (V2): softened hues, shown only on the small chip in Layers and the Properties header. Never on the rail, the canvas or selection.
  • Do the Comfortable sizes feel friendly enough, or one more step up?

Theme notes

Light is the default from round 2. Dark stays a full option.

Dark (option)

Canvas surround darkest, then app chrome, then panels, then raised surfaces (dialogs, popovers). Cool neutrals with a slight indigo bias, so the indigo accent belongs. Text on panels reaches at least 4.5:1; labels stay readable rather than faint.

Matches today's values closely, so B2 (tokens) changes structure, not the look.

Light (default), and Match system

White panels on a near-white app frame, with a grey canvas surround (#e6e7ec) so a white or cream artboard still stands out. The accent darkens to keep 4.5:1 on white. Status hues use darker foregrounds on tinted fills.

Match system follows the OS setting live. The artboard and the canvas overlays (safe, trim, cut, flag) never change with the theme.

F6 region order

  1. Top bar (menus, then document actions)
  2. Rail
  3. Open drawer or Checks panel
  4. View bar
  5. Canvas
  6. Properties | Layers (each tab, or each stacked panel)
  7. Status bar

Visible in the mockups

  • A 2 px focus ring on keyboard focus (component sheet; Settings theme cards).
  • Hit targets 24 px or more; toolbar and rail targets 28 px or more.
  • Every state has a word or icon as well as a colour: Saved/Modified, severity, evidence tier, toggle state.
  • No interface text below 11 px; 11 px is only used for uppercase labels and counts.

Escape order

  • Popover → drawer → mode (text edit, reposition) → selection.
  • Screen-reader support is planned for B24, not in these mockups.
