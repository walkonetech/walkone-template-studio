# Glossary

- **Project** — A single editable working document for one event's template; saved as a native project.
- **Native Project** — The app's own file (working extension `.boothproject`, not final) containing the vendor-neutral `TemplateProject` plus assets. See [DATA_MODEL.md](DATA_MODEL.md).
- **Template** — A reusable, parameterized design (layout, placeholders, background, type, badge, palette roles) that can be applied to a new project.
- **Design Recipe** — A set of creative rules (photo count, background style, frame style, type pairing, palette roles, asset search phrases) used to generate or suggest a starting design; distinct from a template.
- **Canvas** — The editing surface in the editor, including pasteboard, guides, and rulers.
- **Print Canvas** — The bounded area equal to the physical print size at the project DPI; what gets exported.
- **Photo Placeholder** — The designated area where the booth software inserts a captured photo during an event.
- **Photo Layer** — The internal layer type representing a photo placeholder (with photo number, frame, crop behavior); never just a rectangle.
- **Badge** — A parameterized group of text/graphics showing event info (names, date, title, etc.).
- **Overlay** — A graphic layer drawn above photos/other content (e.g., decorative frame, texture).
- **Frame** — The border/decoration around a photo placeholder (solid, double line, Polaroid-style, custom PNG, etc.).
- **Asset** — An imported file (PNG, JPG, WebP, SVG, …) used in a design.
- **Project Asset** — An asset stored inside a project package.
- **Library Asset** — An asset in the user's reusable local library; copied into a project when used.
- **Palette** — A set of colors assigned to semantic roles (primary, secondary, accent, background, text, …).
- **Preflight** — Validation run before export producing errors and warnings.
- **Checks / Checks panel** — (7B B4) the one presentation of preflight and safe-area findings: groups **Error** (blocks export), **Needs attention** (allowed) and **Good to know** (notes, collapsed; never counted as problems — "Ready · n notes"). Repeats are merged into one card; only working actions (Select, Select all, Printer & cutting…, Details). Opens on the left from the top-bar Checks button; Export shows the same cards.
- **Selection toolbar** — (7B B5) the small row of 3–5 actions in words that appears next to the selected layer on the canvas (never in Print Preview); can be turned off in Settings › Editor.
- **Essentials** — (7B B5) the always-visible top of Properties: the fields an operator changes most for that layer type; everything else sits in closed sections with a one-line summary.
- **Settings** — (7B B5) settings of this computer (theme, button size, interface scale, printer, editor helpers); never stored in a project.
- **schemaVersion** — the integer in every `.boothproject`'s `project.json` naming the oldest file-format version whose readers can open it (ADR-060). An older app refuses a newer number with "Update the app". Version 2 (B5.5) is used only by projects that have sheet margins, a separate row gap, top-left placement or a generic safe margin; standard projects are still written as version 1.
- **Access key (mnemonic)** — Windows/Linux: the underlined letter of a menu or menu item; Alt + a menu's letter opens it, the item's letter runs it while the menu is open. Shown only while the menus are used from the keyboard (F10, a tap on Alt). macOS has none (type a letter to jump instead). ADR-061.
- **Forced colours / High Contrast** — Windows Contrast themes replace app colours with system colours (`forced-colors: active`); Template Studio maps focus and selected states to the system Highlight (`styles/a11y.css`). Artwork and exports are not affected.
- **F6 regions** — the window areas F6 / Shift+F6 move between: top bar, rail, drawer, view bar, canvas, Properties/Layers, status bar.
- **Getting-started tips** — (7B B5) the three-step card on a new blank project; not the Design Guide.
- **Format / Custom Format (B5.5, ADR-059)** — what is being designed: design size (inches canonical; entered in in/mm/px) + DPI, plus how it is arranged for output and two pieces of editor guidance (generic safe margin, cut guides). Built-in formats (2×6 strip, 4×6, 6×4) and custom ones share one model (`FormatDefinition`). Distinct from an Output Profile (how it is produced).
- **Output Composition** — how copies of the design are arranged on the print sheet (`project.output`): exact size, or a grid with gaps, optional margins and centred/top-left placement.
- **My formats** — saved custom formats on this computer (`formats.json`, app-local; never in a project; rename/delete; built-ins cannot be deleted).
- **Generic design safe margin** — a format's own keep-safe distance from every design edge (e.g. 3 mm; `canvas.safeMarginMm`). General guidance with no printer evidence; a fitting Output Profile's printer safe areas take precedence.
- **Cut guides** — Print Preview lines where copies are cut apart (and the margin box). Editor guidance only (View › Cut guides); never printed or exported.
- **Printer & cutting** — (7B B4) the user-facing name of the Output Profile dialog: what the printer may trim, the safe line, "How sure are we?" (Estimated · Tested on a print · Measured; "Measured" is not "verified on the production booth"), setup tiles and the evidence under "How do we know?".
- **Fixture** — A real DSLR Booth template export stored in `tests/fixtures/dslrbooth/source/` as a compatibility reference (private client data: local only, never committed).
- **Round Trip** — Converting DSLR Booth → internal → DSLR Booth (or reverse) and checking nothing is lost.
- **DSLR Booth Adapter** — The importer/exporter pair that converts between the internal model and DSLR Booth's format.
- **Flattened Export** — A single merged image (e.g., PNG) of the whole design.
- **Two-Up Strip** — A print layout containing two 2x6 strips side by side on one larger print canvas (exact dimensions printer/template dependent; Needs Validation).
- **Layer Package** — (Phase 6A; not offered in the Export dialog since the owner decision in ADR-041 §8, code kept for 6B) A ZIP of semantic PNG bands split by stack position around the photo slots (background, frames, overlay, text) plus design/proof references, `manifest.json` and `readme.txt`. Not one PNG per layer (ADR-041).
- **Proof PNG** — The print with each photo slot shown as its numbered placeholder, for client approval only; never production artwork. (Before B3.1 it showed sample photos, which were removed.)
- **Print PNG / Design PNG** — Production raster exports: the whole print sheet / one copy of the design. Photo areas empty, native frames drawn.
- **Provider Adapter** — An isolated module integrating an external asset/AI service.
- **Design Guide** — (7C v1) the guided start: Size → Photos → Colors → Text → Review, with a live preview; creates a normal project (numbered photo slots, text layers, Event Palette) and opens it in the editor. One-way in v1; never exports by itself.
- **Starting layout** — (7C) a Design Guide photo arrangement (e.g. Stacked, Grid, One large + two small). Geometry only: once created, every slot is a normal layer; nothing keeps the arrangement.
- **Guide answers** — (7C) the Design Guide's choices; UI state of the running app, never saved in the project.
- **Editor** — the Canva-style canvas editor for power users (exists; redesign planned).
- **Event Theme** — (planned) a saved set of design choices (style, colours, fonts, layout) to start a similar event from.
- **Safe area / 2-inch cut** — the region of a print that survives the printer's cut (a 4×6 cut into two 2×6 strips); content outside it is lost. The cut is printer/driver configuration, never stored in a template.
- **Native strip** — a dslrBooth template whose canvas is one 2×6 strip with `print_2_per_page="True"`; dslrBooth prints it two per 4×6 sheet (`_2x`) and shares the single strip (`_1x`).
- **Two-strip sheet** — a 4×6 dslrBooth template holding two hand-copied 2×6 strips (how existing templates were built); the importer can turn it into one native strip.
- **Import notes** — data from an imported dslrBooth template that Template Studio does not use but keeps verbatim (`sourceCompatibility.dslrbooth`), listed in the import dialog.
- **Company profile** — (planned, shared by Template Studio and WalkOne Booth, never stored in templates) the operator's company details (logos, website, booking number) that "company" elements in templates pull from.
- **Main client** — the event client who approves the template proof before the event; clients never use the app.
- **WalkOne Booth** — (future, ADR-049) the all-in-one local photo booth platform (events, capture, printing, sharing, media) that will replace dslrBooth and contain Template Studio as a module.
- **Template Studio core** — (future packaging) the one shared implementation of the domain, editor, rendering and export used by both the standalone app and WalkOne Booth.
- **Output Profile** — printer/media/finishing description outside the template (ADR-053, `src/output/`): sheet, cut positions, expected trim per edge, keep-safe margins, finishing results, setup guidance; every value carries its evidence. Read by the safe-area overlay and checks; chosen per computer, never saved in a project.
- **Evidence level** — how far an Output Profile value can be trusted: Unknown, Nominal, Inferred, Provisional, Observed on test laptop, Owner-measured, Verified on production booth.
- **Expected trim** — the strip of the print expected to be lost at an edge (overscan/trim); **keep-safe margin** — the distance critical content should keep from an edge or cut.
- **Event Readiness** — (future, WalkOne Booth) the pre-launch check of camera, printer, template, sharing and storage.
- **Booth Health** — (future, WalkOne Booth) the event-day status dashboard (camera, printer, queues, storage, errors).
- **Approved event revision** — (future) the immutable version of a template the client approved for an event.
